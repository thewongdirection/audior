audior.
Command-line microphone & system-audio recorder for Windows
Strict C on the Windows SDK — WASAPI capture, Media Foundation MP3 encoding, zero third-party dependencies
Windows 10 & 11 Two editions · C + PowerShell WAV & MP3 output
1Core capabilities

Microphone recording

Captures any active input endpoint through WASAPI, straight to WAV or MP3.

System audio capture

WASAPI loopback records whatever the playback device is mixing — --include-output.

Merge or separate

One mixed file at a chosen mic share (default 65/35), or aligned _mic + _system tracks.

Microphone gain

--amplify 0–300 boosts the mic only: 0 = unity, 100 = 2×, 300 = 4×.

Device control

List every capture and playback endpoint; select by ID, list index, or name substring.

Streams to disk

Ring buffer plus a writer loop keep memory bounded at any recording length.

Two ways to stop

Press Enter, or run --stop elsewhere — a named event, crossing windows and editions.

Live progress

A single in-place status line reports seconds and bytes written on every flush.

3Command reference
OptionArgumentWhat it does
-o, --output<file>Output path. Required to record; extension corrected to match the format.
-f, --formatwav | mp3Output format. Default mp3.
-i, --include-output—Also capture system audio via WASAPI loopback.
--merge[percent]Mix both sources into one file; percent is the mic's share (default 65).
--separate—Write two aligned files: _mic and _system.
-m, --mic<id|index|name>Microphone to record. Default: system default capture device.
-a, --amplify<0-300>Linear gain on the mic stream. Default 0 (unity).
-d, --output-device<id|index|name>Playback device to capture for loopback. Default: system default.
-l, --list-devices—List all capture and playback devices, then exit.
-s, --stop—Stop a recording started by another instance and finalise its files.
-h, --help—Show help and exit. Exit codes: 0 success · 1 error.

Typical invocations

audior --list-devices
audior --output meeting.mp3
audior --output talk.wav --format wav
audior --output session.mp3 -i --merge --amplify 50
audior --output call.wav -f wav -i --separate
4Requirements

Supported OS

  • Windows 10 or Windows 11 — the only supported platforms.
  • Uses in-box WASAPI and Media Foundation; no runtime beyond the Windows C runtime.
  • MP3 encoding needs Media Foundation, which is absent on “N” editions without the Media Feature Pack.
  • Microphone access must be allowed under Settings → Privacy & Security → Microphone.

To build the C edition audior.exe

  • MSVC cl.exe — Visual Studio 2022, any edition.
  • Windows SDK 10.0.19041.0 or later.
  • Run build.bat from a Developer Command Prompt.
  • Compiled as C (/TC). MinGW, Clang-cl and cross-compilation are not supported.

To run the PS edition audior.ps1

  • No build step — the C# audio engine is compiled at run time by Add-Type.
  • Windows PowerShell only; no external modules.
  • If execution policy blocks it: powershell -ExecutionPolicy Bypass -File .\audior.ps1
Good to know — loopback records the device mix, so it captures silence when nothing is playing · resampling is linear interpolation, suited to speech and general recording · --amplify can clip a loud source · MP3 is fixed at 128 kbps stereo at compile time · one session per process.
